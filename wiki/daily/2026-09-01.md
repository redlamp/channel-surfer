## Fresh-eyes review (Fable 5.1)

Taylor asked for a review of the whole project, wiki and code. Findings,
ranked: phones got an unusable app (rail covered the grid), the canvas
component had grown to 1400 lines, Reset to defaults duplicated the
store's defaults, colour maths lived in four places, removing the last
library image could strand the canvas, keyboard access was thin, dark was
forced while a light palette shipped unused, and nothing was tested.
Taylor took every item; the deploy-workflow note was a misunderstanding
(it already does exactly what he wants: dev is only rebuilt when main
is pushed, and he tests dev locally).

## Shipped on `dev` (six branches, each `--no-ff`)

- **fix/color-math-and-remove-fallback** — `pixelHue` and the sRGB
  transfer functions join `lib/color.ts`; the readout conversions share
  one hue routine. `remove()` retries the primary demo when the library
  empties and the demos never loaded; the empty canvas says "Drop an
  image" instead of "Loading".
- **refactor/canvas-split** — `breakdown-canvas.tsx` becomes a 190-line
  shell over `components/canvas/`: pure geometry, a `SceneState` ref, and
  hooks for decode, camera framing, uniform sync, overlay placement,
  pointer gestures, keyboard. Gotcha: the React Compiler lint forbids
  mutating a plain hook argument, so the state travels as a ref named
  `sceneRef` and is only touched inside effects, handlers, and frame
  callbacks — the same rule that produced `canvasBridge` on 08-23.
- **feature/mobile-layout** — below 48rem the inspector starts closed
  and opens as a 55dvh bottom sheet; `viewInsets` gains `bottom`; a
  500ms single-finger press opens the effect menu (touch has no
  right-click) via a new `canvasBridge.tileAtScreen`; chrome changes
  refit the view unless the user has panned by hand.
- **feature/settings-reset-and-theme** — `DISPLAY_DEFAULTS` /
  `WORKSPACE_DEFAULTS` and a `reset()` action replace the hand-kept
  setter list. Theme setting (dark / light / system): a pre-paint script
  in the root layout reads the persisted value, `ThemeSync` follows
  changes, `color-scheme` follows the class.
- **feature/test-harness** — see [[decision-verification-harness]]:
  45 unit tests, 3 Playwright shader tests covering all effects but
  warm/cool, `ci.yml`, `bun run check`. AGENTS.md now says which to run
  first.
- **chore/hygiene-and-gamut** — scaffold SVGs gone, `package.json`
  version 0.3.1, CI pins bun from `packageManager`, 3.5KB `icon-40.png`
  replaces the 130KB master in the header, ESLint ignores `.remember/`.
  Gamut: `Display` row in the Inspect tab (P3 / Rec. 2020 detection,
  "tiles sRGB" caveat), JPEG ICC profiles named from their `desc` tag,
  and [[../research/wide-gamut|wide-gamut]] takes stock of what a P3
  path would need. Accessibility gaps filed as
  github.com/redlamp/channel-surfer#2.
