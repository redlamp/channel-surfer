## RGB colorize toggle (feature/rgb-colorize-toggle)

- Single click on any R/G/B tile toggles the trio between black→white and
  black→channel-color (uRgbColorize uniform, cross-faded in useFrame).
  Click is guarded: drag-release ignored via e.delta, and the toggle waits
  250 ms so a double-click (framing) cancels it.
- GPU-verified both modes plus the halfway blend.

  [[../notes/decision-web-refactor-stack|the stack's]] lib/image-details.ts.
- **feature/tile-keyboard-nav** — arrow keys step between neighboring
  tiles while framed (clamped at edges, keys swallowed so the page never
  scrolls, form controls left alone).
- **fix/ux-defaults-reticle** — library closed by default, highlight
  default now "Hue tile" (persist v1 migration), reticle regrown to 32px
  with a 14px clear center window.
- **fix/snap-interactions** — REAL flicker root cause found after Taylor
  reported it persisted: the inline `uniforms={{...}}` prop is a new
  object each render, so hover re-renders made R3F re-apply it and reset
  every uniform (uRgbColorize → 0, cross-fade restarts = grayscale
  flicker on the RGB tiles). Fixed by memoizing the uniforms object per
  texture. Also per Taylor: hue retarget and arrow-key navigation now
  snap instead of tweening (double-click framing keeps its tween).
