### Gotcha worth remembering

A newly-lit button computed as `transparent` with the correct class
applied — looked like a specificity/token bug between two elements with
identical class lists. Cause: the Browser pane was hidden, and **CSS
transitions never advance in a non-compositing tab**, so
`getComputedStyle` returns the frozen start value. `el.style.transition
= "none"` returns the truth. Saved to global memory alongside the
hidden-tab WebGL note.
